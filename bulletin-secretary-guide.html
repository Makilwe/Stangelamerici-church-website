How to Update the Weekly Bulletin

Cómo actualizar el boletín semanal — St. Angela Merici Catholic Church

You do not need to touch the website. You only edit a simple table (Google Sheet). The website reads it and updates itself — usually within a few minutes.

Usted no necesita tocar el sitio web. Solo edita una tabla sencilla (Google Sheet). El sitio web la lee y se actualiza solo — normalmente en unos minutos.

The 4 steps / Los 4 pasos

  1. Open the bulletin table using the link you were given. Leave it bookmarked.
    Abra la tabla del boletín con el enlace que le dieron. Guárdelo en favoritos.
  2. Add a new row at the very top, right under the titles (click the row number “2” → Insert row above).
    Agregue una fila nueva arriba del todo, justo debajo de los títulos.
  3. Fill in the 5 boxes (see the table below). Write English first, then Spanish, like the printed bulletin.
    Llene las 5 casillas (vea la tabla abajo). Escriba primero en inglés y luego en español, como el boletín impreso.
  4. Close the table. That’s it — the website updates by itself.
    Cierre la tabla. Eso es todo — el sitio web se actualiza solo.

The 5 boxes / Las 5 casillas

Box / CasillaWhat to write / Qué escribir
dateThe Sunday of that week, like 2026-10-04 (year-month-day).
El domingo de esa semana, como 2026-10-04 (año-mes-día).
sunday_titleThe Sunday name, e.g. Twenty-Seventh Sunday in Ordinary Time.
announcementsParish news. Leave an empty line between each announcement.
Noticias parroquiales. Deje una línea vacía entre cada anuncio.
intentionsMass intentions, one per line.
Intenciones de Misa, una por línea.
pdf_urlLink to the full PDF bulletin, if there is one. May be left empty.
Enlace al boletín completo en PDF, si hay uno. Puede dejarse vacío.

Good to know / Conviene saber

Made a mistake? Just fix the box in the table — the website corrects itself.
¿Cometió un error? Solo corrija la casilla en la tabla — el sitio web se corrige solo.
Old rows are the archive. Never delete old rows; they become the “Past Bulletins” list automatically.
Las filas viejas son el archivo. Nunca borre las filas anteriores; se convierten solas en la lista de “Boletines Anteriores”.
Not showing yet? Wait about 5 minutes and refresh the page. If it still doesn’t appear, call the contact below.
¿No aparece todavía? Espere unos 5 minutos y actualice la página. Si aún no aparece, llame al contacto de abajo.
